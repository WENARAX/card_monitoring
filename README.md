# Мониторинг операций по банковским картам

Прототип по записке: рабочее место читает данные через GraphQL, у API своей базы нет. Внутренние сервисы хранят объекты из главы 2.2, каждый в своей базе SQLite.

Сервисы: карточки, операции, оценка риска, инциденты, доступ. Mock-клиент вызывает сервис в том же процессе. Вызова gRPC нет: интерфейс клиента уже отделён, чтобы позже подставить транспорт.

Держатель карточки пользователем не является. Полный номер карточки не хранится. Модель машинного обучения и брокер сообщений не используются.

```bash
cd monitoring
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest tests.test_reads
.venv/bin/python -m graphql_api.app
```

Резолвер только вызывает сценарий. Сборка очереди, карточки операции, списка правил и отчёта находится в `graphql_api/services/monitoring.py`.

Запрос отправляется методом POST на `http://127.0.0.1:8080/graphql`. Тело:

```json
{"query": "{ incidentQueue { status amount maskedPan } }"}
```
